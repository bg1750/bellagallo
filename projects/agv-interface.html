AGV Control Interface

Improved an interface for Savannah River National Laboratory specializing in LiDAR, vision, and encoder sensor fusion. RTOS motion control achieving sub-10ms response times across a multi-robot factory floor deployment.

PLC LiDAR RTOS Ladder Logic Sensor Fusion
[ - ]

An operator-facing control interface for a fleet of automated guided vehicles on a production floor, surfacing live position, sensor health, and controls without adding latency that could affect vehicle safety.

  • Live floor map rendered from fused LiDAR, camera, and wheel-encoder data, showing each vehicle's path and nearby obstacles.
  • Commands relayed to the vehicle's RTOS layer with sub-10ms round-trip execution, and PLC interlocks monitored and overridden from the interface.
  • Built on the same operator-interface approach as a crawler-robot control dashboard I developed at the lab, including real-time telemetry, command dispatch, and a live 3D roll/pitch/yaw orientation display.
