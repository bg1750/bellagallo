Calorimeter Heating System

Designed and built the user interface for a calorimeter heating system at Savannah River National Laboratory, providing real-time temperature monitoring and precise control for laboratory use.

Visual Basic Hardware Interface Real-Time Monitoring

A software interface for a calorimeter heating system used in lab experiments, with precise temperature control and continuous data logging.

  • Live temperature readings from the sensor array, charted over time so researchers can watch heating curves.
  • Configurable setpoints, ramp rates, and hold times sent to the hardware controller, with visual confirmation on each change.
  • Automatic timestamped logging to file for post-experiment analysis.
