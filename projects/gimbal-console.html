Pan-Tilt Gimbal Control Console

A desktop operator console for a two-axis camera platform, built in Python and PyQt6. It has live attitude instruments, pan, tilt, and zoom controls, connection monitoring for each subsystem, and a latching emergency stop. A built-in simulator drives everything, so it runs end to end with no hardware attached.

Some of my professional work can't be shown publicly, so I built this as a stand-in. It uses the same design patterns and interface techniques I developed on the job, applied to a neutral example and wired to a software simulator instead of real hardware.

An operator console for a two axis camera gimbal. A software simulator drives it, so you can watch the horizon move and every control respond with no hardware attached.

  • Artificial horizon and heading compass, both drawn from scratch with Qt's painter (no image assets).
  • Slew-rate gear, pan jogs, a type-to-set tilt angle, and a motorized zoom stage.
  • Connection status for five subsystems, with offline ones blinking.
  • A latching emergency stop that freezes all motion and flashes until reset.

The GUI only talks to a small simulator interface, so a real serial or fieldbus backend with the same methods would drive hardware unchanged.
