OCR System

Automated Optical Character Recognition pipeline for industrial inspection at Savannah River National Laboratory. Identifies and validates equipment labels regardless of orientation, using 360° rotation scanning and multi-step verification.

Python EasyOCR OpenCV NumPy GPU Accelerated Affine Transforms PyTesseract
Live Demo EasyOCR PyTesseract

The production system and its data can't be shown publicly, so the live demo is a generic version. It runs the same pipeline (full 360° rotation scanning, confidence-filtered detection with bounding boxes, and token classification with error correction for common misreads) on a synthetic label of standard words and numbers, so nothing is tied to the real parts, fields, or environment.

An OCR system that automates reading and validating equipment labels during industrial inspection, a task previously done manually and prone to orientation-related misreads.

  • Each image is rotated through a full 360° sweep in 10° steps (36 angles) so labels read regardless of orientation, exiting early at the first angle that passes validation.
  • PyTesseract (chosen over EasyOCR in testing) handles extraction, with custom logic on top: GPU-accelerated inference at every angle and a substitution engine that corrects common misread characters.
  • A multi-step validation pipeline, built from scratch, confirms every required field is present and correctly formatted before emitting a confirmed reading.
