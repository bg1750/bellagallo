Picoammeter Readout

A desktop operator panel for a low-current measurement setup, built in Python with tkinter. A large live current readout plus controls for zeroing, gain, autorange, alarms, and temperature correction, behind a password gate. A built-in simulator drives it, so it runs with no hardware attached.

Some of my professional work can't be shown publicly, so I built this as a stand-in. It uses the same operator panel and the same file-based frontend/backend split, wired to a simulator instead of the real instrument.

Live Page GitHub

An operator panel for a picoammeter, a low-current measurement setup with a transimpedance amplifier. A software simulator stands in for the real instrument, so you can watch the readout come alive and cycle through warmup, settle, zero, and measure.

  • Large current readout, auto-scaled from fA up to mA, colored by alarm state.
  • State, stability, gain, temperature, overload, alarm, and connection fields.
  • Zero, set gain, autorange, high/low alarm levels, and optional temperature correction.
  • A password gate on every settings change.

The frontend never talks to hardware directly. It reads a status file and writes a command file, so a real device backend writing the same status would drive the instrument unchanged.
